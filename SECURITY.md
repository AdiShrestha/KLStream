## Reporting a Vulnerability

The KLStream team takes security and memory safety seriously, especially given our lock-free concurrency and low-latency systems focus.

If you discover a security vulnerability or potential memory safety / data race issue in KLStream:

1. **Do not** create a public GitHub issue.
2. Please report the issue privately by emailing the maintainers or filing a confidential security advisory on GitHub.
3. Provide detailed steps to reproduce the vulnerability, including:
   - Platform and compiler versions
   - Minimal reproduction code or thread sanitizer trace
   - Potential impact of the issue

We appreciate your responsible disclosure and will respond promptly to verify and address reported issues.
